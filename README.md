# 🌧️ Rainfall Prediction in Australia

A machine learning project designed to forecast whether it will rain tomorrow in Australia based on daily weather observations.

## 🎯 Objectives
- Build an end-to-end predictive pipeline using Australian meteorological data.
- Handle missing observation data and class imbalances without data leakage.
- Compare multiple classification algorithms to discover the optimal model.
- Deploy an intuitive web dashboard and REST API for real-time forecasting.

## 📊 Dataset Overview
The dataset contains ~140,000 daily weather observations collected across Australian weather stations from 2007 to 2017.
Primary target variable: `RainTomorrow` (Binary: Yes / No).
